# ハルニレ開発標準 コーディング規約（架空・検証用）

## HR-STD-01 例外メッセージ
例外メッセージの先頭には必ずエラーコードを付ける。形式は「HRE-」に4桁の数字を続ける（例：HRE-0412）。
数字の上1桁は発生層を表す。0=画面層、4=業務層、7=データ層。

## HR-STD-02 ログ出力
ログは1行1イベントとし、レベルは TRACE を使わない。
本番相当の環境では DEBUG を出力しない。ログファイルは日付ごとに分け、保存期間は37日とする。

## HR-STD-03 命名
定数名は「k」で始めるキャメルケースとする（例：kMaxRetryCount）。
非同期メソッドの末尾には Async を付ける。
